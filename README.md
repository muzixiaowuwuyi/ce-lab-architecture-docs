# CE-Lab Architecture Documentation

This repository contains the comprehensive deployment documentation for the Week 2 Cloud Engineering Lab.

## 🚀 Project Overview
The goal of this project is to design and document a secure, high-availability three-tier architecture on AWS, featuring automated load balancing and network isolation.
